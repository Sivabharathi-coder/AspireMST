📦 2. Install Starter Dependencies
Install React and ReactDOM:

bash
Copy
Edit
npm install react react-dom
Install development dependencies:

bash
Copy
Edit
npm install --save-dev webpack webpack-cli webpack-dev-server
npm install --save-dev babel-loader @babel/core @babel/preset-env @babel/preset-react
npm install --save-dev html-webpack-plugin
📦 Breakdown:
Package	Purpose
webpack	Core bundler
webpack-cli	CLI tool for webpack
webpack-dev-server	Dev server with live reloading
babel-loader	Loader for Webpack to use Babel
@babel/core	Babel compiler core
@babel/preset-env	For compiling modern JS
@babel/preset-react	For compiling JSX
html-webpack-plugin	Generates an HTML file and injects the bundle
